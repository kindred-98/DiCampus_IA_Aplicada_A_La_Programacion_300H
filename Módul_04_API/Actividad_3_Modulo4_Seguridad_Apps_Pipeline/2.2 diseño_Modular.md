## Ejemplo de código modular

### clasificador.py

```python
from openai import OpenAI
import os
import json

client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

SYSTEM_PROMPT = """Eres un clasificador de tickets de soporte técnico.
Clasifica el ticket en:
- Categoría: [técnico, facturación, cuenta, otro]
- Prioridad: [alta, media, baja]
Responde SOLO en JSON: {"categoría": "...", "prioridad": "..."}"""

FEW_SHOT = """
Ejemplo 1: "No puedo iniciar sesión" → {"categoría": "cuenta", "prioridad": "alta"}
Ejemplo 2: "Quiero cambiar mi plan" → {"categoría": "facturación", "prioridad": "media"}
"""

def clasificar(ticket_texto):
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": SYSTEM_PROMPT},
            {"role": "user", "content": f"{FEW_SHOT}\nTicket: {ticket_texto}"}
        ],
        temperature=0.0,  # Consistencia máxima
        max_tokens=100
    )
    return json.loads(response.choices[0].message.content)
```

### buscador.py

```python
from openai import OpenAI
from sklearn.metrics.pairwise import cosine_similarity

client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# Base de conocimiento (se indexa una sola vez)
documentos = [
    {"id": 1, "titulo": "Cómo reiniciar el servidor", "contenido": "Pasos para reiniciar..."},
    {"id": 2, "titulo": "Error de conexión", "contenido": "Solución cuando no conecta..."},
]

embeddings = []

def indexar_base():
    global embeddings
    for doc in documentos:
        emb = client.embeddings.create(
            model="text-embedding-3-small",
            input=doc["contenido"]
        )
        embeddings.append(emb.data[0].embedding)

def buscar(query, top_k=3):
    query_emb = client.embeddings.create(
        model="text-embedding-3-small",
        input=query
    ).data[0].embedding
    
    similitudes = []
    for i, doc_emb in enumerate(embeddings):
        sim = cosine_similarity([query_emb], [doc_emb])[0][0]
        similitudes.append((i, sim))
    
    similitudes.sort(key=lambda x: x[1], reverse=True)
    return [documentos[i] for i, _ in similitudes[:top_k]]
```

## Ventajas de esta modularización

| Ventaja | Descripción |
|---------|-------------|
| **Testabilidad** | Cada módulo se puede probar independientemente |
| **Reutilización** | El buscador puede usarse en otras apps |
| **Mantenimiento** | Cambios en clasificación no afectan generación |
| **Escalabilidad** | Añadir análisis de voz sin tocar lo demás |
| **Debugging** | Facilita identificar dónde falla cada cosa |
