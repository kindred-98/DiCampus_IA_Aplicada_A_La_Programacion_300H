# 🔁 Sistema Reutilizable para Cualquier Proyecto Python

> Pipeline completo de prompts que puedes aplicar a cualquier proyecto desde cero.

---

## FASE 1 — Definir proyecto

```
Actúa como arquitecto de software.

Quiero desarrollar una aplicación en Python.

Idea del proyecto:
[tu idea]

Define:

1. propósito del proyecto
2. funcionalidades principales
3. stack tecnológico recomendado
4. arquitectura sugerida
5. posibles dificultades técnicas
```

---

## FASE 2 — Arquitectura

```
Diseña la arquitectura del siguiente proyecto:
[descripcion]

Incluye:

1. patrón de arquitectura
2. estructura de módulos
3. flujo de datos
4. diagrama textual
```

---

## FASE 3 — Roadmap

```
Crea un roadmap profesional para desarrollar este proyecto.

Divide el desarrollo en fases:

1. configuración
2. desarrollo core
3. integración
4. testing
5. optimización
6. despliegue

Cada fase debe incluir tareas claras.
```

---

## FASE 4 — Estructura del proyecto

```
Genera una estructura profesional de carpetas para este proyecto Python.

Incluye:
- src
- tests
- config
- scripts
- docs

Muestra la estructura en árbol.
```

---

## FASE 5 — Generación de código

```
Actúa como desarrollador Python senior.

Implementa el siguiente módulo:
[modulo]

Requisitos:
- código limpio
- tipado
- manejo de errores
- comentarios
```

---

## FASE 6 — Testing

```
Crea tests usando pytest para este módulo.

Incluye:
- tests unitarios
- casos límite
- manejo de errores
```

---

## FASE 7 — Optimización

```
Analiza este código Python y detecta:

- problemas de rendimiento
- problemas de arquitectura
- posibles mejoras
```

---

## FASE 8 — Seguridad

```
Actúa como experto en seguridad.

Analiza este proyecto Python e identifica:
- vulnerabilidades
- problemas de autenticación
- problemas de manejo de datos
```

---

## FASE 9 — Docker

```
Genera todo lo necesario para dockerizar este proyecto.

Incluye:
- Dockerfile
- docker-compose
- variables de entorno
```

---

## FASE 10 — Producción

```
Explica cómo desplegar esta aplicación en producción.

Incluye:
- servidor recomendado
- configuración
- CI/CD
- monitorización
```
