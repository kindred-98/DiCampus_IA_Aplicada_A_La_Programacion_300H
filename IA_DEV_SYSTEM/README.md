## 🧠 Los 3 métodos del sistema

### R.C.T.A.F
`Rol → Contexto → Tarea → Atributos → Formato`
Estructura básica para cualquier prompt de desarrollo.

### S.P.E.C.A.R
`System → Proyecto → Entorno → Constraints → Acción → Respuesta`
Método avanzado para obtener código de calidad senior.

### AI Development Loop
`Definir → Arquitectura → Plan → Código → Review → Optimizar → repeat`
Flujo de trabajo completo para cualquier feature o proyecto.

## 📌 Prompts esenciales (los más usados)

**Arrancar cualquier proyecto:**
```
Quiero que actúes como arquitecto de software y desarrollador Python senior.
Me ayudarás a desarrollar una aplicación completa desde cero.
No avances a la siguiente fase hasta que yo lo indique.
```

**Antes de pedir cualquier código:**
```
Antes de escribir código:
1. analiza el problema
2. propone la arquitectura
3. explica el enfoque
4. luego genera el código
```

**Code review rápido:**
```
Actúa como code reviewer senior.
Revisa este código Python y detecta bugs, malas prácticas y problemas de rendimiento.
```
