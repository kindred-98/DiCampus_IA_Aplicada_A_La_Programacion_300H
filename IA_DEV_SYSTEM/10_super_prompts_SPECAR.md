# ⚡ SUPER PROMPTS para Programadores — Método S.P.E.C.A.R

> Cómo hacer que la IA piense como un senior engineer y genere código de mucha mayor calidad.

---

## ¿Qué es S.P.E.C.A.R?

| Letra | Concepto | Qué define |
|-------|----------|------------|
| **S** | System / Rol | El experto que debe ser la IA |
| **P** | Proyecto | Descripción completa del proyecto |
| **E** | Entorno técnico | Stack y tecnologías usadas |
| **C** | Constraints | Restricciones y requisitos de calidad |
| **A** | Acción | Qué debe hacer exactamente |
| **R** | Respuesta esperada | Formato y estructura del output |

---

## S — System (Rol experto)

Define el perfil experto antes de pedir cualquier cosa.

```
Actúa como:

- arquitecto de software
- desarrollador Python senior
- experto en clean architecture
```

> Esto cambia completamente la calidad del resultado.

---

## P — Proyecto

Explica el proyecto con contexto suficiente.

```
Estoy desarrollando una aplicación en Python para analizar textos.

La aplicación permitirá:
- contar palabras
- analizar frecuencia
- exportar resultados
```

---

## E — Entorno técnico

Define el stack exacto para que la IA no asuma tecnologías.

```
Tecnologías:

- Python 3.12
- arquitectura modular
- CLI
- pytest para testing
```

---

## C — Constraints (restricciones)

Uno de los pasos más importantes. Sin esto la IA toma atajos.

```
Requisitos:

- código limpio
- tipado
- manejo de errores
- funciones pequeñas
- arquitectura escalable
```

---

## A — Acción

Di exactamente qué quieres que implemente.

```
Implementa el módulo de análisis de palabras.
```

---

## R — Respuesta esperada

Define el formato para que la respuesta sea siempre consistente.

```
Formato de respuesta:

1. explicación breve
2. diseño de la solución
3. código completo
4. ejemplo de uso
```

---

## ✅ Ejemplo completo S.P.E.C.A.R

```
Actúa como desarrollador Python senior y arquitecto de software.

Proyecto:
Estoy desarrollando una aplicación CLI en Python que analiza textos
y cuenta palabras.

Entorno técnico:
- Python 3.12
- arquitectura modular
- uso de typing
- pytest para tests

Requisitos:
- código limpio
- funciones pequeñas
- manejo de errores
- docstrings

Tarea:
Crear el módulo que analiza un texto y devuelve:
- número de palabras
- número de caracteres
- frecuencia de palabras

Formato de respuesta:
1. explicación breve
2. diseño de la solución
3. código completo
4. ejemplo de uso
```

## 🚀 Super Prompt Master

Úsalo al inicio de cualquier proyecto para convertir la IA en tu tech lead completo.

```
Quiero que actúes como:

- arquitecto de software
- desarrollador Python senior
- experto en buenas prácticas

Tu objetivo es ayudarme a desarrollar una aplicación completa en Python
desde cero hasta producción.

Trabajaremos en fases:

1. definición del proyecto
2. arquitectura
3. roadmap
4. estructura del proyecto
5. desarrollo de módulos
6. testing
7. optimización
8. seguridad
9. dockerización
10. despliegue

Reglas:
- no avances a la siguiente fase hasta que yo lo indique
- explica decisiones técnicas
- usa buenas prácticas
- genera código limpio y modular
```

---

## 💡 Truco Anti-Errores

Antes de pedir cualquier código, añade esto al prompt.
Reduce drásticamente los errores de la IA.

```
Antes de escribir código:

1. analiza el problema
2. propone la arquitectura
3. explica el enfoque
4. luego genera el código
```
