# 🏗️ Prompts — Diseño de Proyecto

> Bloque 1 de 5 del Prompt Engineering Kit para Python.

---

## Prompt 1 — Definir idea del proyecto

```
Actúa como arquitecto de software senior.

Quiero desarrollar una aplicación en Python.

Idea del proyecto:
[explica tu idea]

Define:

1. objetivo del proyecto
2. funcionalidades principales
3. usuarios del sistema
4. tecnologías recomendadas
5. posibles retos técnicos

Devuelve la información estructurada.
```

---

## Prompt 2 — Análisis de viabilidad

```
Actúa como arquitecto de software.

Analiza la viabilidad de este proyecto Python:
[descripcion del proyecto]

Evalúa:
- complejidad
- tecnologías necesarias
- tiempo estimado de desarrollo
- posibles dificultades

Propón mejoras.
```

---

## Prompt 3 — Arquitectura del sistema

```
Actúa como arquitecto de software.

Diseña la arquitectura para este proyecto:
[descripcion]

Incluye:
- patrón arquitectónico
- componentes del sistema
- flujo de datos
- tecnologías
```

---

## Prompt 4 — Roadmap de desarrollo

```
Actúa como tech lead.

Crea un roadmap completo para desarrollar este proyecto en Python.

Divide el proyecto en fases:

1. configuración
2. desarrollo core
3. integración
4. testing
5. optimización
6. despliegue
```

---

## Prompt 5 — Estructura de proyecto

```
Genera una estructura profesional de carpetas para este proyecto Python.

Incluye:
- src
- tests
- config
- scripts
- docs

Muestra el árbol del proyecto.
```
