# 📋 MEGA Plantilla Profesional de Prompts

> Plantilla universal para casi cualquier desarrollo en Python con IA.

---

## 🧱 Estructura base

```
ROL
Actúa como [rol experto].

CONTEXTO
Estoy desarrollando una aplicación en Python.

DESCRIPCIÓN DEL PROYECTO
[explicación del proyecto]

OBJETIVO DE ESTA TAREA
[qué quieres que haga la IA]

REQUISITOS TÉCNICOS
- lenguaje
- framework
- base de datos
- arquitectura
- librerías permitidas

RESTRICCIONES
- código limpio
- buenas prácticas
- modularidad
- escalabilidad

FORMATO DE RESPUESTA
1. explicación breve
2. arquitectura o lógica
3. código completo
4. sugerencias de mejora
```
