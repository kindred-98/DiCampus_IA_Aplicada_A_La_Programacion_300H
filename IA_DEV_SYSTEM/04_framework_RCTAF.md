# 🧠 Framework R.C.T.A.F — Prompting para Mejor Código

> Método estructurado para obtener código de mayor calidad cuando trabajas con IA.

---

## ¿Qué es R.C.T.A.F?

| Letra | Concepto | Qué define |
|-------|----------|------------|
| **R** | Rol | El experto que debe ser la IA |
| **C** | Contexto | El proyecto y situación actual |
| **T** | Tarea | Qué debe hacer exactamente |
| **A** | Atributos | Cómo debe ser el resultado |
| **F** | Formato | Cómo quieres recibir la respuesta |

---

## R — Rol

Define el experto que necesitas.

```
Actúa como desarrollador Python senior especializado en arquitectura de software.
```

---

## C — Contexto

Explica el proyecto con claridad.

```
Estoy desarrollando una aplicación web en Python usando Flask.
```

---

## T — Tarea

Di exactamente qué debe hacer.

```
Crea el módulo de autenticación.
```

---

## A — Atributos

Cómo debe ser el resultado.

```
- código limpio
- tipado
- manejo de errores
- modular
```

---

## F — Formato

Cómo quieres recibir la respuesta.

```
1. explicación
2. estructura
3. código completo
```

---

## ✅ Ejemplo completo con R.C.T.A.F

```
Actúa como desarrollador Python senior.

Estoy desarrollando una aplicación CLI para analizar textos.

Tarea:
Crear una función que cuente palabras y caracteres.

Atributos:
- código limpio
- tipado
- manejo de errores
- docstrings

Formato:
1. explicación
2. código
3. ejemplo de uso
```

---

## 🚀 Prompt Maestro (BONUS)

Úsalo al inicio de cualquier proyecto para convertir la IA en tu tech lead.

```
Quiero que actúes como:

- arquitecto de software
- desarrollador senior Python
- experto en buenas prácticas

Me ayudarás a crear una aplicación completa en Python
desde cero hasta producción.

Trabajaremos en fases:

1. definición
2. arquitectura
3. roadmap
4. desarrollo
5. testing
6. optimización
7. despliegue

No avances a la siguiente fase hasta que yo lo indique.
```
