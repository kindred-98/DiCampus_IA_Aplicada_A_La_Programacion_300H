# 3.1 — Pipeline CI/CD con GitHub Actions

## Ejemplo de workflow completo (.yml)

```yaml
name: CI/CD - Sistema de Soporte con IA

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
      - name: Checkout código
        uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: cachede pip
        uses: actions/cache@v4
        with:
          path: ~/.cache/pip
          key: ${{ runner.os }}-pip-${{ hashFiles('requirements.txt') }}
          restore-keys: |
            ${{ runner.os }}-pip-

      - name: Instalar dependencias
        run: pip install -r requirements.txt

      - name: Ejecutar tests
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
          GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}
        run: pytest tests/ -v

      - name: Verificar clasificación
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
        run: python -c "from clasificador import clasificar; print(clasificar('No puedo iniciar sesión'))"

  build:
    needs: test
    runs-on: ubuntu-latest
    if: github.event_name == 'push'
    
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Instalardependencias
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
        run: |
          pip install -r requirements.txt
          python -c "print('Sistema listo para producción')"
```

---

## Puntos clave de seguridad en el pipeline

| Práctica | Cómo se implementa |
|---|---|
| **API keys en Secrets** | `env: OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}` |
| **No exponer keys en logs** | Usar `set -o pipefail` y evitar `echo $OPENAI_API_KEY` |
| **Rate limiting** | Configurar en la consola de OpenAI, no en el pipeline |
| **Alertas de presupuesto** | Crear alert en OpenAI Dashboard ($10/mes máximo) |
| **Solo en push a main** | `if: github.event_name == 'push'` evita ejecuciones innecesarias |

## Errores comunes en pipelines con IA

| Error | Causa | Solución |
|---|---|---|
| **API key no disponible** | No se pasó como env | Verificar que el Secret existe y está bien referenciado |
| **Rate limit excedido** | Muchas ejecuciones | Reducir frecuencia o usar workflow_dispatch |
| **Timeout** | La IA tarda en responder | Aumentar timeout en el step: `timeout-minutes: 10` |
| **Coste inesperado** | Bucle infinito en tests | Limitar número de tickets de prueba |
