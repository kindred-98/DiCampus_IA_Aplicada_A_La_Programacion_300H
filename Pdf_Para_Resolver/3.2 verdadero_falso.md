# 3.2 — Verdadero o Falso: Pipeline con APIs de IA

| V / F | Afirmación | Justificación si es Falsa |
|---|---|---|
| **V** | Las API keys deben almacenarse como GitHub Secrets, nunca en el código ni en el `.yml` directamente. | — |
| **V** | Un pipeline puede disparar miles de llamadas a la API si hay un bucle infinito o una mala configuración. | — |
| **V** | El verdadero reto del coste no es el precio por llamada, sino controlar el uso descontrolado. | — |
| **V** | Si el proveedor de IA sufre una caída, el pipeline con manejo de errores puede hacer reintento automático. | — |
| **V** | Gemini Flash y GPT-4o-mini son los modelos más recomendados para pipelines de alta frecuencia. | — |
| **F** | Una vez integrada la API en el pipeline, ya no hace falta monitorizar el consumo. | **Incorrecto.** El consumo debe monitorizarse siempre mediante dashboards y alertas para detectar usages anómalos, prevenir facturas inesperadas y optimizar costes. |

---

## Explicaciones detalladas

### 1. API keys en GitHub Secrets
Las API keys nunca deben estar en el código ni en logs. GitHub Secrets cifra las claves y las inyecta como variables de entorno solo en runtime.

### 2. Riesgo de bucle infinito
Un `while True` o un test mal configurado puede generar miles de llamadas. Ejemplo: 500 tickets × 10 reintentos = 5000 llamadas en minutos. Coste: ~$10 en lugar de $0.50.

### 3. Coste controlado
El precio por llamada es bajo ($0.0004), pero con volumen alto puede subir rápido. 10,000 llamadas/día = ~$4/día = $120/mes.

### 4. Manejo de errores
Con `try/except` y `retry` podemos manejar 5xx de OpenAI. Pero rate limits (429) deben manejarse con backoff exponencial.

### 5. Modelos recomendados
 GPT-4o-mini y Gemini Flash son los más económicos. Para pipelines de alta frecuencia, no tiene sentido usar GPT-4o a $0.01/call cuando mini cuesta 20x menos.

### 6. FALSA - Monitorización siempre necesaria
Aunque el pipeline funcione, hay que monitorizar:
- Consumo diario de tokens
- Costes acumulados
- Errores recurrentes
- Latencia de respuestas
